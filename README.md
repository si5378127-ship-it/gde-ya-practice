# А где в своей жизни сейчас Я?

Интерактивная психологическая мини-практика Анастасии Кутузовой.

## Технологии

- React
- TypeScript
- Vite

## Особенности

- mobile-first
- без backend
- без аналитики
- ответы хранятся локально в браузере
- персональный результат
- сохранение карточки 1080×1080

## Локальный запуск

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
